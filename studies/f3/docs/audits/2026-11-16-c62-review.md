## Diagnostic illustrating the count distinction

This is a review counterexample, **not a new accepted paper result**. In the
same fixed windows, retaining Oman gives one early unit and 75 later units,
76 in total. Conditional on that total, a two-rate model has

`p = rho*G / (rho*G + L)` and `P(X <= 1) = (1-p)^76 + 76*p*(1-p)^75`.

Setting this probability to 0.05 gives `p = 0.06090271422847843`,
`rho = 0.1188809944823619`, reciprocal **8.411773508072**. This differs from
both the no-Oman zero-count 13.3866 and C61's exact-oldest-conditioned Oman gap
calculation. It illustrates why the positive cannot be invoked while retaining
the empty-interval count. It remains a retrospective benchmark with selected
windows, not an estimate or selection-calibrated confidence statement about
the actual historical reduction. An independent `Beta(2,75)` 0.95 quantile
check gives the same probability and factor.

Reproduce the diagnostic without production functions:

```python
G, L, n = 454.41 - 432.9, 432.9 - 393.47, 76
lo, hi = 0.0, 1.0
for _ in range(160):
    p = (lo + hi) / 2
    tail = (1 - p)**n + n*p*(1 - p)**(n - 1)
    if tail > 0.05:
        lo = p
    else:
        hi = p
p = (lo + hi) / 2
rho = L/G * p/(1 - p)
print(p, rho, 1/rho)
```
